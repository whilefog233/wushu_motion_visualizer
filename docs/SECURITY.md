# Security Policy

## Supported Versions

This project is currently maintained as an early local research and training visualization tool. Security updates are handled on the default maintained branch.

## Reporting a Vulnerability

Please report security issues privately through GitHub's security reporting tools if available, or by opening an issue without including exploit details.

When reporting, include:

- A clear description of the issue
- Steps to reproduce
- Affected files or features
- Any suggested mitigation

Please do not upload private training videos or personal data when reporting an issue.
